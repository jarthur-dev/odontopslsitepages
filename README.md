O **Odonto PSL** é um website institucional moderno e totalmente responsivo desenvolvido para uma clínica odontológica. O objetivo principal do projeto é transmitir credibilidade, apresentar os tratamentos oferecidos, a infraestrutura da clínica e facilitar o agendamento de consultas através de chamadas para ação (CTAs) estratégicas.

---

### 🚀 Funcionalidades Principais

- **Design Premium & Clean:** Cores e tipografia selecionadas para passar a sensação de higiene, modernidade e confiança.
- **Seção de Especialidades:** Apresentação clara de serviços (Ortodontia, Implantes, Clareamento, Estética Facial, etc.).
- **Totalmente Responsivo:** Experiência de navegação fluida adaptada para smartphones, tablets e desktops.
- **Botões de Conversão Rápida:** Integração com canais de atendimento (WhatsApp/Agendamentos) otimizando a captação de pacientes.
- **Seção Sobre a Clínica:** Espaço dedicado para contar a história, apresentar os profissionais e a infraestrutura.
